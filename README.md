# FahrMit Landingpage

Einfache Landingpage für die FahrMit-App (Fahrgemeinschaften in Österreich).

## Live-Version
Nach Aktivierung von GitHub Pages erreichbar unter:
`https://<dein-github-username>.github.io/fahrmit-landing/`

## Setup GitHub Pages
1. Repo auf GitHub erstellen (z.B. `fahrmit-landing`)
2. Diese Datei `index.html` hochladen
3. Unter Repo → Settings → Pages → Branch "main" → Ordner "/ (root)" auswählen → Save
4. Nach 1-2 Minuten ist die Seite live
